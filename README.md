# PUMA560-Robust-Control

Robust Min-Max vs Nominal Computed Torque Control for the **PUMA 560 robotic manipulator**
implemented in **MATLAB**.

---

#📌 Project Overview
This project was completed as part of **Robot Manipulators**.
The objective is to compare the performance of:
- Nominal Computed Torque Control (PD + Inverse Dynamics)
- Robust Min-Max Control

under **model uncertainty and unknown payload disturbances**.

---

# Features
- Full dynamic modeling of the PUMA 560 robot
- Joint-space trajectory tracking
- Robust control design
- Performance comparison under disturbances
- MATLAB-only implementation (no Simulink)
